## Cómo usar las soluciones

1. Haz primero el ejercicio.
2. Abre el `README.md` de su carpeta y comprueba el mínimo esperado.
3. Revisa los criterios de corrección antes de comparar frases concretas.
4. Abre los artefactos ampliados solo para entender decisiones o localizar un fallo.
5. No busques coincidencia literal: comprueba claridad, trazabilidad y coherencia.

Una solución diferente también es válida si cumple el ejercicio. Una respuesta más larga no es necesariamente mejor.

> [!NOTE]
> Durante la reorganización se conservan temporalmente algunas rutas antiguas como pequeños ficheros de compatibilidad. Su única función es dirigir a estas carpetas y evitar que fallen enlaces ya compartidos; no contienen soluciones duplicadas.
