# Diagramas en SVG

> **Para quién:** quien prepare presentaciones o documentos · **Tiempo de lectura:** ~1 min · **Nivel:** 🟢 básico

Estas son las exportaciones en SVG de todos los diagramas del repositorio. Son imágenes vectoriales: se pueden ampliar sin perder calidad y el texto sigue siendo texto. Sirven para PowerPoint, Keynote, Word o cualquier documento. Si vas a usar Google Slides, que no admite SVG, usa las de [png/](../png/README.md).

Se generan automáticamente a partir de los ficheros de [diagramas/](../README.md): no las edites a mano. Si cambias un diagrama, hay que volver a exportarlo (lo explica [CONTRIBUIR.md](../../CONTRIBUIR.md)).
