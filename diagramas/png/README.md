# Diagramas en PNG

> **Para quién:** quien prepare presentaciones, documentos o mensajes · **Tiempo de lectura:** ~1 min · **Nivel:** 🟢 básico

Estas son las exportaciones en PNG de todos los diagramas del repositorio, con fondo blanco y a doble resolución para que se lean bien proyectadas. Sirven para Google Slides, el correo, un chat o cualquier sitio que admita imágenes. Si necesitas ampliarlas mucho, usa las de [svg/](../svg/README.md).

Se generan automáticamente a partir de los ficheros de [diagramas/](../README.md): no las edites a mano. Si cambias un diagrama, hay que volver a exportarlo (lo explica [CONTRIBUIR.md](../../CONTRIBUIR.md)).
